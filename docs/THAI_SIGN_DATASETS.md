# แหล่งข้อมูลและโมเดลภาษามือไทย/อเมริกัน

> **อัปเดต:** ตอนนี้ระบบใช้ TSL-51 (เทรนเองด้วย `ml/train_tsl.py`) และโมเดล ASL อันดับ 1 จาก Kaggle (250 คำ) แล้ว ดู README หัวข้อ “ผลวัด” โฟลเดอร์ `research/` ที่เอกสารนี้อ้างถึงถูกย้ายออกจาก git ไปไว้ที่ `%USERPROFILE%\.signvoice\research` และโมเดล ASL 36 คลาส/ไทย 17 คำด้านล่างไม่ได้ใช้แล้ว เพราะโมเดลใหม่ครอบคลุมกว่า

ตรวจสอบวันที่ 5 พฤศจิกายน 2569 เพื่อเลือกข้อมูลสำหรับต่อยอด SignVoice Local คำว่า “อังกฤษ” ในตารางหมายถึง **American Sign Language (ASL)** ซึ่งเป็นภาษามืออีกภาษา ไม่ใช่การนำท่ามือไทยมาเปลี่ยนคำพูดเป็นอังกฤษ

### ผลการตรวจ TSL‑51 ด้วยไฟล์จริง

- HF API แสดงไฟล์ 1,830 รายการ มีวิดีโอใน `videos/` 911 ไฟล์ และไฟล์ landmark ใน `landmarks/` 914 รายการ (บางรายการเป็น zip) คำอธิบายชุดข้อมูลระบุวิดีโอ `user_sign` 547 คลิป และ `user_sentence` 252 คลิป
- ดาวน์โหลด `metadata/user_sign_metadata.csv` ได้ 547 แถว และตัวอย่าง `สวัสดี_อายุเท่ากันหรือน้อยกว่า_0.mp4` ได้จริง คลิปเปิดด้วย OpenCV ได้: 640×480, 30 fps, 92 เฟรม (~3.1 วินาที)
- CSV landmark ของคลิปเดียวกันมี 92 แถว 176 คอลัมน์: `frame`, `t_ms`, พิกัดมือ/แขน/ใบหน้า และค่าการมองเห็น/การปรากฏบางจุด ข้อมูลขาดหายบางจุดเป็นช่องว่าง ต้องจัดการ NaN ก่อนฝึก
- [dataset card](https://huggingface.co/datasets/Namonpas/thai-sign-language-tsl51) ระบุว่าข้อมูล expert ส่วนหนึ่งมาจากแหล่งภายนอกและอาจมีข้อจำกัดสิทธิ์ ควรใช้ `user_sign` กับ `user_sentence` สำหรับการทดลองการศึกษา และตรวจสิทธิ์ก่อนใช้เชิงพาณิชย์
- จำนวนวิดีโอ/แลนด์มาร์กข้างต้นเป็นผลจากรายการไฟล์ที่เผยแพร่ ณ วันที่ตรวจ ไม่ใช่จำนวนตัวอย่างที่มีหลัง augmentation ภายใน zip

เก็บตัวอย่าง 1 คลิปและ CSV ที่ตรงกันไว้ใน [`research/tsl51-sample/`](../research/tsl51-sample/) เพื่อทดลอง pipeline โดยไม่ต้องดาวน์โหลดชุด 2.46 GB ทั้งหมด ตัวอย่างนี้มีป้ายกำกับ “สวัสดี (ใช้กับผู้มีอายุเท่ากันหรือน้อยกว่า)” จาก TSL‑51 และยัง **ไม่ได้** ใช้ทดสอบความแม่นยำของ SignVoice ปัจจุบัน

## โมเดลที่ฝึกมาแล้ว

| โมเดล | อินพุต/ผลลัพธ์ | ทดลองที่ทำแล้ว | ข้อจำกัด |
|---|---|---|---|
| [b1ll1eee/sign-language-recognition](https://github.com/b1ll1eee/sign-language-recognition) (MIT) | Keras LSTM `30×258` MediaPipe Holistic → 17 คำไทย; ไฟล์ `test.h5` ~2.9 MB | ดาวน์โหลด weights ได้จริงและตรวจโค้ดลำดับ class แล้ว | ต้องมี pose + 2 มือครบตามสูตรเดิม, TensorFlow 2.11/Python รุ่นที่รองรับ; ผลใน README เป็นของผู้ทำ ยังไม่ได้ทดสอบกับกล้องของเรา; โค้ดตัวอย่างมี MongoDB URI ฝังไว้ จึงไม่ควรรันทั้งเว็บโดยตรง |
| [meprxxw/Thai-Sign-Language](https://github.com/meprxxw/Thai-Sign-Language) | TFLite Transformer ~21 MB, MediaPipe Holistic 543 จุดต่อเฟรม | ตรวจว่ามีไฟล์โมเดลและโค้ดอินพุตจริง | ไม่พบ LICENSE ชัดเจน จึงยังไม่คัดลอก weights/code เข้ามาในรีโปเรา; อินพุตหนักกว่า pipeline ปัจจุบันมาก |
| [nocontextdoruk/asl-landmark-mlp](https://huggingface.co/nocontextdoruk/asl-landmark-mlp) (CC BY‑NC 4.0) | ONNX `1×63` จาก 21 จุดมือ → 36 คลาส A–Z/0–9 | ดาวน์โหลด ONNX 223,407 ไบต์, โหลดด้วย ONNX Runtime CPU และรัน inference ได้ ผลลัพธ์ `1×36` ไม่มี NaN | เป็น **ASL ตัวอักษร/ตัวเลขแบบนิ่ง** ไม่ใช่คำหรือประโยค; ค่า 100% validation ใน model card ยังไม่ได้ยืนยันกับผู้แสดงใหม่ |

สำเนา weights ไทยและ ASL พร้อมไฟล์สิทธิ์ของต้นทางอยู่ใน [`research/models/`](../research/models/) เพื่อใช้ทดลองแบบออฟไลน์ น้ำหนักทั้งสองยัง **ไม่ได้** ถูกต่อเข้ากับแอป: การ smoke test ASL ใช้อินพุตศูนย์เพื่อตรวจเพียงว่า ONNX โหลดและคำนวณได้ ไม่ได้ยืนยันความถูกต้องของการทำนายท่าจริง

โมเดลภาษาอังกฤษตัวเล็กนี้เข้ากับการตรวจมือในหน้าเว็บมากที่สุด แต่ต้องทำ wrist-relative/scale normalization ตาม model card และเพิ่ม runtime ONNX ในเว็บ ส่วนโมเดลไทย 17 คำและ TSL‑51 ต้องเพิ่ม **pose landmarks** และตัวสะสมเฟรมต่อเนื่อง ปัจจุบัน SignVoice ใช้ MediaPipe Gesture Recognizer + Face Landmarker ซึ่งยังไม่ให้ feature vector ที่โมเดลไทยทั้งสองต้องการ

## แผนที่ทำทันหนึ่งวัน

1. เก็บเดโมปัจจุบันที่ทำงานได้จริงไว้เป็นฐานการสื่อสารสองภาษา และอธิบายชัดว่า mapping ท่าพื้นฐานยังไม่ใช่การแปลภาษามือไทย/ASL
2. ถ้าจะเพิ่มคำไทยแท้ก่อนสอบ ให้เลือก 3–5 คำจาก TSL‑51 (`สวัสดี`, `ขอบคุณ`, `ฉัน`, `คุณ`, `สบายดี`) แล้วฝึก classifier แบบลำดับเฟรมบน landmark ที่มีอยู่ พร้อม **แยกผู้แสดง/คลิปต้นฉบับ** ระหว่าง train/test; หลีกเลี่ยงการแบ่งเฟรมจากคลิปเดียวกันข้ามชุด
3. ถ้าจะเพิ่ม ASL ให้เริ่มจากโมเดล ONNX 36 คลาสแบบสะกดนิ้วมือ โดยเลือกโหมด ASL แยกจากโหมดภาษามือไทย และแสดง confidence + ให้ผู้ใช้ตรวจแก้ก่อนพูด
4. ตัววัดผลที่ควรรายงาน: จำนวนคลาส, จำนวนผู้แสดง, ความแม่นยำบนผู้แสดง/คลิปที่ไม่เคยเห็น, confusion matrix, latency บนเครื่องเดโม และกรณีไม่มีท่า (`null_act`) ไม่ให้สร้างคำผิด

การเลือกภาษาเสียงพูดไทย/อังกฤษเป็นขั้นหลังการรู้จำท่ามือ ไม่ทำให้โมเดล ASL รู้จำ TSL หรือกลับกันโดยอัตโนมัติ
